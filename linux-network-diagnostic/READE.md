Linux Network Diagnostic Tool

Project Overview

A Python-based tool that collects network information and performs basic connectivity and DNS checks.

Features

- Hostname and operating system detection
- Network interface information
- Ping-based connectivity check
- DNS resolution check
- Text report generation

Technologies

- Python
- Linux networking commands
- CCNA networking concepts
- Git and GitHub

How to Run

Run the program from the project directory:

python3 main.py

On Windows, use:

python main.py

Note

Network results depend on the machine's operating system, network configuration, firewall, and connectivity.
